#测验-AI

Quiz AI 是一款面向中文用户的本地优先 AI 刷题 Android App。它把「AI 出题、资料导入、题库管理、刷题、错题复习、学习统计」串成一条完整的学习闭环，界面采用浅色卡片风格，并配有悬浮导航、渐变主题和较多界面动效

## 下载

最新版本：[Quiz-AI1.0.0正式版](https://github.com/LiangJM666/Quiz-AI/releases)

这是一个可以直接安装使用的中文刷题 App，名为 **Quiz AI，当前版本 1.0.0，minSdk 26 / targetSdk 37）。它把「用 AI 生成题目」「导入现成资料」「按题库练习」「错题复习」「学习统计」串成一条完整的学习流程；所有数据都存在本机，不需要自建服务器。

## 一、它解决的问题

- 手头没有题库时：输入一个主题，让 AI 生成一套题（10/20/50 道）。
- 手头有资料时：把 Excel、Word、TXT 或直接粘贴的文字，解析成可以练习的题库。
- 练习时：单选、判断、填空三种题型都能判分；答错自动进入错题本，答对自动移出。
- 想坚持时：连续学习天数、今日进度、正确率、近 7 天答题量与正确率曲线。
- 想好看时：浅色卡片 + 渐变 Hero + Aurora 背景光晕，6 套主题色、6 档字号。

## 二、页面与功能

**首页**：AI 学习计划 Hero（今日进度 x/20）、连续学习/今日答题/正确率三张统计卡、「最新题库」卡片（显示最近保存的题库名、题数、预计用时，点击后先选顺序/随机再开练；没有题库时显示空状态并引导去生成或导入）、AI 生成入口、题库管理、错题本。

**生成**：输入练习主题、选择题型（单选/判断/填空）、题量，可上传题干截图做「图片识题」；生成时逐个点亮步骤、流式展示思考过程，完成后可「保存到题库」。API 设置支持预设与自定义，深度思考可开关。

**导入**：先说明「单选题 / 判断题 / 填空题」，下面才是选择文件与文字导入。
- 文件：Excel（.xlsx）、Word（.docx）、TXT；旧版 .doc/.xls/PDF 会明确提示另存。
- 文字：粘贴后自动按内容判断题型，填空题里连续两个及以上空格（含全角空格）会变成 `____` 下划线。
- 示例：「示例」给一份单选+判断+填空混合文本，「Excel 示例」给一份可解析的表格样例。
- 解析成功后规范成统一文本，可直接开练或保存成题库。

**刷题**：点选即判；答对默认自动下一题（可在设置改成停留看解析），答错抖动并展开解析。判断题只有「正确/错误」两个大按钮；填空题在答题页直接输入答案并自动比对（支持多个可接受答案）。结果页有分数滚动、达标彩纸，无标准答案的题以「待核对」模式练习、不计入正确率。

**题库管理 / 错题本**：题库卡片点击后先选「顺序练习/随机练习」；两页都支持「管理」多选、全选、已选计数、批量删除二次确认（管理态隐藏单行删除）。错题本按题干去重、答错累计次数、重练答对自动移除。

**我的**：头像/昵称编辑、累计答题与正确率、学习记录（按天列表 + 近 7 天双折线图）、外观偏好（蓝色/青绿/紫罗兰/珊瑚/琥珀/海蓝 6 主题 × 6 档字号，立即生效）、答题方式、关于 Quiz AI（版本、项目地址）。

## 三、AI 接口

- 协议：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages，可自动识别 URL 协议。
- 预设：DeepSeek（`deepseek-flash`）、MiMo（`mimo-v2.6-pro`）、Qwen（`qwen4-max`）、智谱（`glm-5.3-flash`），四家都按支持识图配置；也支持完全自定义接口与模型名称。
- 「测试连接」会逐个协议发一条极小请求，逐行报告可用性；对 GLM5.3 Flash 这类先思考后回答的模型会留足 token，并把思考通道内容当成功。
- 每个服务商的 Key 分开保存，切换服务商不会清空已填内容；Key 只存本机。

## 四、技术实现

| 项目 | 说明 |
| --- | --- |
| 语言/UI | Java 17，Android 原生 View + XML + Drawable + ValueAnimator |
| 架构 | 8 个 Gradle 模块：`:app`、`:core`、`:navigation`、5 个 `:feature:*`，单向依赖，页面只通过 `PageHost` 通信 |
| 第三方依赖 | 运行时零第三方库；网络用 `HttpURLConnection` + `org.json`，Excel/Word 解析自研（ZIP + DOM/SAX） |
| 存储 | SharedPreferences（资料/API/统计）+ 应用私有 JSON（题库、错题），题库保存原始文本、打开时重新解析 |
| 数据量 | 单次导入/生成最多 50 题，每日统计保留 120 天 |

设计系统集中在 `:core`：一套颜色/字符串/Drawable/样式，6 套主题色板通过主题属性下发，`Anim` 动效库统一处理进场、按压、脉冲、抖动、展开、切页，并在 Robolectric 环境自动降级，保证截图稳定。

## 五、质量与构建

- 单元/渲染测试：`:core` **39 个**、`:app` **50 个**（文字解析、Excel 三种模板、DOCX、三种协议与流式思考、API 地址归一化、存储与统计、各页面 Robolectric 渲染与交互流程），当前全部通过。

## 六、边界与限制

- 只支持 `.xlsx` / `.docx`，老格式需另存；Excel 必须有表头且表头下有数据行，只有表头会提示「请补充题目」。
- AI 生成需要自备 API Key，且服务端要按提示词返回 JSON 题目数组；不支持离线生成。
- 纯本地单机：没有账号、云同步和多端同步；题库与错题不会跨设备。
- 界面与题目面向中文内容设计，未做多语言。
